Quiz response analytics

Every completed quiz on this device/browser is recorded locally (nothing is sent anywhere by default). Download the file below and hand it to a Claude thread — it's structured JSON with the mode, every answer, the winner and the top-5 for each response. To pool responses from all visitors into a Google Sheet, see the note at the bottom.

Pooling responses from every visitor

This site is static (GitHub Pages), so there's no server to collect responses on. The zero-cost fix: create a Google Form with one Paragraph question, link it to a Sheet, and paste its two IDs into assets/analytics-config.js (instructions are in that file). From then on every visitor's completed quiz is appended to your Sheet as one JSON row — a live file you can point Claude at any time.

Responses contain no names, accounts, or identifiers — just quiz answers and timestamps.
